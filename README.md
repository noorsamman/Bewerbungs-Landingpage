# Bewerbungs-Landingpage

Meine persönliche Bewerbungsseite für die Suche nach einem Pflichtpraktikum als Fachinformatiker für Systemintegration.

Die Seite ist bewusst einfach gehalten: reines HTML und CSS, ohne Framework. Für das Hosting gibt es im Ordner `docs/` einen kleinen Express-Server.

## Aufbau

| Datei | Zweck |
|---|---|
| `index.html`, `style.css` | Die Seite selbst |
| `docs/` | Kopie der Seite mit `server.js` für das Hosting |

## Lokal starten

Einfach `index.html` im Browser öffnen.

Oder mit dem Server:

```bash
cd docs
npm install
npm start
```

Danach läuft die Seite unter http://localhost:3000.
